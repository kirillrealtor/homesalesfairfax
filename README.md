# homesalesfairfax.com

Premier digital real estate portal for **Fairfax County, Northern Virginia**, featuring active Bright MLS listings, seller in-home consultation booking, computational home valuation benchmarks, and direct client-side tour coordination.

## Key Features
- **Seller-First Acquisition Engine:** In-home listing appointment scheduler and localized comp estimates across Fairfax City, Mosaic District, Oakton, Burke, and surrounding submarkets.
- **Active MLS Property Feed:** Searchable listing inventory with direct client-side showing requests.
- **Client-Side Communication Architecture:** Native SMS, WhatsApp, and direct calling hooks for rapid lead conversion without backend database friction.
- **Submarket Landing Hubs:** Dedicated, SEO-optimized landing pages for high-demand Northern Virginia neighborhoods.
- **Interactive Tools:** Fairfax County property tax and mortgage calculator, neighborhood comp breakdowns, and live market trends.

---

## Tech Stack
- **Framework:** Next.js 16 (App Router with Turbopack)
- **Styling:** Custom Vanilla CSS Design System with mobile-first responsive architecture
- **SEO:** Dynamic XML sitemaps, robots.txt, OpenGraph and Twitter card metadata

## Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build

# Start production server
npm start
```
